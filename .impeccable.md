## Design Context

### Users
Analysts, developers, and project managers at IIEG Jalisco (Instituto de Información Estadística y Geográfica de Jalisco). They use this internal tool during office hours on desktop to catalog and navigate data sources across a 7-level hierarchy (proyectos → productos → tablas → bases de datos → instrumentos → URLs → archivos). The primary job: register, find, and manage data assets efficiently. Context is professional, focused, data-dense workflows.

### Brand Personality
Institutional, precise, efficient. The interface should feel trustworthy and capable — not cold or bureaucratic. Established palette: brand purple (#5C2472) + orange accent (#FF8300), light theme.

### Aesthetic Direction
Clean light-mode UI. Not a generic government portal. No dark mode needed. The existing brand palette (purple primary, orange accent) is intentional and should be respected. Typography: currently Inter — functional, clean, not flashy. Anti-reference: nothing that feels like a generic gov portal (dense, dated, form-heavy) or an aggressive dark dashboard.

### Design Principles
1. **Clarity first** — information hierarchy over decoration; every element earns its place
2. **Efficient navigation** — deep hierarchies must feel shallow; users should reach any record in 2 clicks
3. **Institutional confidence** — purple communicates authority, orange signals action; use sparingly
4. **Data-density with breathing room** — tables and lists are the core UI; they need space to scan, not cards
5. **No AI tells** — distinctive enough that it doesn't look AI-generated, clean enough that it doesn't distract
